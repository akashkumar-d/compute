# Docs

Notes, instructions and experiment write-ups for this repo.

Files here are committed to git, so they outlast any single Claude Code
session. Files left only in a session's container are lost when it ends.

- One Markdown file per topic, e.g. `running-experiments.md`.
- Date-prefix experiment logs, e.g. `2026-09-27-baseline.md`.
- Never put API keys, tokens or passwords here.
