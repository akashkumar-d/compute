# Transition rule and pure cubic teacher prototype

Prepared source only. No old kernels or results are changed, and these files do not authorize training. Root owns the separate student prototype. No teacher/student model is imported or evaluated by the scalar test.

`transition_rule.transition_nodes(bias,scale,order=8,limit=12.0)` returns nodes and **standard-normal-weighted**, composite Gauss-Legendre weights. The partition contains the clipped base breaks `[-12,-8,-5,-3,-1,0,1,3,5,8,12]`, the interval endpoints, and any mapped gate levels `(-12,-6,-3,-1,0,1,3,6,12)` lying inside the interval. Breaks are sorted and deduplicated. Scale must be nonnegative; zero uses only base breaks. Each piece has `order` nodes. Integration is explicitly truncated to `[-limit,limit]` and weights are never renormalized. This is a targeted finite rule, not an error bound; especially when multiplied by high-degree polynomials, small Gaussian tail mass alone is not a truncation certificate.

The optional keyword `extra_gates=()` accepts additional `(bias,nonnegative_scale)` pairs and unions their transition breaks into the same partition; it adds no mixture weights or normalization. With a negative projected coefficient, the caller may flip both its bias and coefficient since the transition-level list is symmetric. This supports the outer partition of a separate pair prototype; it does not evaluate either gate.

`silu_derivatives(x,max_order=6)` is exposed from both `transition_rule` and `teacher_h3`; its list is indexed by derivative order, so `[0:3]` supplies S, S′, S″. The scalar implementation uses `exp(-abs(x))`, computes logistic derivative factors `r(1-r) P_n(r)` at `r<=1/2`, and reflects positive arguments to preserve tiny derivatives when sigmoid rounds to one. The exact polynomial recurrence is `P_(n+1)=(1-2r)P_n+r(1-r)P_n′`; SiLU derivatives use `S^(k)=x q^(k)+k q^(k-1)`.

`teacher_h3.teacher_terms_h3(pi,p0,nu,v0,coefficients,gamma,order=8,limit=12)` returns `(t,gp,gv)` for the **pure** teacher `gamma*sum_i c_i*He3(x_i)/sqrt(6)` and SiLU gate times linear value. Coefficients are supported on the first r coordinates. Inputs have shapes `(d,m)`, `(m,)`, `(d,m)`, `(m,)`, `(r,)`; gradient outputs include bias rows `(d+1,m)`. Finite positive teacher variance is required. Coefficients and gamma are not renormalized; pass the original gamma, normally `1/sqrt(sum(c_i**2))` for unit variance. No mixed Hermite or raw-link teacher is supported.

The identities and gradients are exactly those in `../weak_link_next/MECHANISM_NEXT.md`: with `D=p·v`, `C3=sum(c_i*p_i^3)`, `C21=sum(c_i*p_i^2*v_i)` and `A_k=E[S^(k)(p0+||p|| Z)]`, the correlation is `gamma/sqrt(6) * [C3*(v0*A3+D*A4)+3*C21*A2]`. The exact Gaussian identity `grad_p A_k=p*A_(k+2)` gives a division-free formula, including at `||p||=0`. The implementation substitutes the transition rule for each A_k. These are gradients of the teacher correlation; the loss factors `-2(alpha/m)a` and student terms are the caller's responsibility. A zero-mean h3 teacher needs no teacher/intercept derivative correction; the centered student Gram still matters.

The integral identities are exact; the finite, parameter-dependent quadrature is approximate. Its analytical-gradient approximation is not automatically the exact derivative of the discretized correlation. Before any scientific use, root must review the source and run a separately approved bounded server fixed-state probe checking directional finite differences, order refinement, student/teacher additivity and appropriate tail sensitivity. No such evaluations were run here.

The one local scalar test checks Gaussian moments, explicit truncated mass, the logistic derivative polynomials, SiLU derivatives at zero and in saturated tails, derivative parity, and JSON round-trip. It does not call `teacher_terms_h3`, `E.evaluate`, a teacher constructor, or a training routine.
