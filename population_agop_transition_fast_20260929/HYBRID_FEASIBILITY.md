# Feasibility of error-controlled hybrid student moments

**Design only.** A hybrid is plausible if most ordered pairs are inexpensive and accurately integrated by vectorized Gauss–Hermite (GH); it is not yet justified for trajectories. Keep the reference transition rule for diagonal moments and the existing pure-h3 teacher formula. Change only off-diagonal student-pair integration. Retain the reference orthogonal/reorthogonalized conditional geometry, stable SiLU derivatives, rank tolerance, coefficient orientations, teacher normalization, centering and original gradient objective. Do not reintroduce the old GH engine's residual-variance floor or unstable derivative evaluation as part of a speed optimization.

**Concrete candidate.** At a state, evaluate all off-diagonal pair moments with GH32 and GH64, in bounded vectorized chunks. Use GH64 provisionally. Compute the difference for every required pair field, including AGOP fields, then propagate those differences through the actual coefficients `alpha/m`, `a_j*a_k`, parameter vectors and head-rate weighting. Refine ordered-pair/reverse-pair groups with the largest estimated contribution using the unchanged transition rule at order16/limit12. Each orientation retains its own reference partition; do not replace directed moments by transposes. Stop refinement only when *all* estimated budgets below are met. If most pairs require transition evaluation, use full reference and record that the hybrid offers no useful speedup.

Let `V=Var(Y)` (one here), `g=(gP,gV,ga)`, `D=m*(gP,gV,head_lr*ga)` and `s=max(1,||theta||2)`. Suggested **engineering validation tolerances**, not learning criteria:

| Quantity | Initial admission tolerance against the available reference |
|---|---|
| Full loss | `abs(Lhybrid−Lref)/V <= 1e-7` |
| Actual weighted update | `||Dhybrid−Dref||2 <= 1e-4*||Dref||2 + 1e-10*m*V/s`; report each block separately and do not accept a wrong direction hidden by the absolute floor |
| Slope along common unit direction `u=Dref/||Dref||` | `abs((ghybrid−gref)·u) <= 1e-4*abs(gref·u) + 1e-10*V/s` |
| AGOP matrix `M` | `||Mhybrid−Mref||F <= 1e-6*||Mref||F`; near zero or unresolved rank gap: use full transition diagnostics, not an arbitrary absolute alignment tolerance |

For AGOP interpretation additionally compare matrix error with the reference rank-r eigengap: require `||delta M||2 <= 1e-3*(lambda_r−lambda_(r+1))` before treating the hybrid leading subspace as numerically interchangeable. If this condition or the existing resolution guard fails, preserve unresolved status and use reference AGOP. This is an integration-admission check, not a replacement AGOP success criterion or formal subspace certificate. Refit should initially remain reference-only: tiny Gram errors can be amplified by the unrestricted cutoff solve, so a loss/gradient/AGOP check alone cannot authorize hybrid refit.

Use both the directly assembled differences and a cancellation-resistant estimate. For example, the student quadratic-loss estimate is `(alpha/m)^2 * sum_jk |a_j*a_k|*|delta G_jk|`; propagate each moment discrepancy through the absolute coefficients of the inherited gradient formulas, then bound the norm after block-rate scaling. For AGOP, an available conservative *propagation of the estimated discrepancies* is `(alpha/m)^2 * sum_ab |delta C_ab|*||W_a||*||W_b||`, with `W=[pi,nu]` and the head products included in `C`. This prevents apparently small signed full sums from hiding large uncertain contributions. Use a predeclared safety factor, e.g.10, on these estimates for refinement admission. Do not tune that factor to a learning outcome.

GH32/GH64 agreement is **only an error indicator**. Both rules can miss a narrow biased transition or share aliasing error; cancellation can hide an incorrect gradient, and a tiny or changing rank gap can amplify AGOP error. A safety multiplier cannot turn their difference into a rigorous bound. Fixed-state reference comparisons must also test the pairs that the estimator labels safe. Record estimator effectivity (observed reference discrepancy / estimated discrepancy), including false-safe pairs and near-zero denominators. A false-safe aggregate invalidates the proposed admission rule for that regime; refine to reference rather than quietly loosening tolerance. True mathematical error bounds would require separate quadrature/tail/derivative analysis, outside this bounded design.

**Avoid changing the numerical objective within a step.** Choose one refinement mask and one GH order for a base state, then keep that mask fixed for the complete finite-difference stencil and every trial step in a line search. If any trial fails the error budget, enlarge the mask, reevaluate the base and all compared trials, and restart that step decision. Never compare a low-accuracy base loss with a differently masked trial loss. Between accepted states use a conservative union/hysteresis policy; before dropping refinements compare old/new masks at the same state and require the above budgets plus loss-switch error below `0.01` times the proposed predicted loss decrease. If the predicted decrease is too small to resolve, retain the more accurate mask. Even a fixed mask does not make analytic population gradients the exact derivative of finite quadrature, so the existing two-epsilon directional consistency screen remains mandatory. No Armijo/training implementation is authorized by this note.

**Small fixed-state validation.** Use all four already pinned full-width anchors 472,473,2260,2261 from the saved probe input, with exact original P/V/a, m64/alpha, teacher and head rate. Do not regenerate or select neurons. Freeze orders, budgets and mask policy first. At each anchor obtain GH32, GH64, the hybrid and transition16/limit12 base outputs (at most16 full-width evaluations, reusing matching pinned reference outputs). Compare all required pair/diagonal/teacher fields, assembled loss, three gradient blocks, weighted direction, Gram/p11 symmetry, AGOP and dropped residuals; count refined pairs and false-safe pairs. Reuse every available order12/16 and limit10/12 comparison; unavailable reference checks stay explicitly incomplete. At anchors472 and2260, add the existing two central-difference epsilon scales under a fixed mask (eight hybrid loss calls; at most24 calls total). Refine/restart events must be reported, not omitted from the cap. Record one-thread server time and memory under a separately reviewed deadline; no automatic trajectory follows a pass. Only proceed if reference accuracy is itself supported at the tested anchors, all numerical tolerances pass, and measured total cost including GH screening and refinement materially improves on full reference.
