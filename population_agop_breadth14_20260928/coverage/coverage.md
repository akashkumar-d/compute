## Normalization, algorithms and what existing positives establish

For one raw q, define mu=E[q(Z)],s2=E[q(Z)^2],D=s2+7mu^2. The target is Y=(sum_i q(X_i))/sqrt(8D); E[Y^2]=1,E[Y]=sqrt(8)mu/sqrt(D),Var(Y)=(s2-mu^2)/D. The raw mean is retained. Both new students profile a separate output intercept; this changes the learner, not the teacher. Their initial raw constant baseline is Var(Y), which can be much smaller than1. Raw baseline-normalized losses and actual raw losses must both be shown. ReLU saves raw MSE; SwiGLU saves MSE/Var(Y), requiring exactly one multiplication by the saved variance. Its existing teacher moments use finite-order piecewise quadrature, not an exact certification.

The new all-profiled ReLU recipe differs from the historical no-intercept cubic successes even when the target mean is zero, because the student output mean is removed dynamically. Historical comparisons are contextual. SwiGLU head_lr0.01 changes the head vector field while all parameter blocks train; it is distinct from a small initial head_ratio. Student widths, initializations, rates and refit classes differ, so the new screen is not a matched student comparison.
